COUTELYA V0.2.1 - améliorations

1. Les cartes colorées du tableau de bord sont cliquables.
   - Commandes en cours -> Commandes
   - À livrer / prêtes -> Livraisons
   - Commandes livrées -> Livraisons
   - Commandes en retard -> Livraisons

2. Le libellé « Commandes » de la barre de navigation est conservé au pluriel et réduit pour tenir sur une seule ligne.

3. Lors d'une nouvelle commande, des listes de choix sont proposées pour :
   - modèle / type de vêtement ;
   - tissu ;
   - couleur.
   Chaque liste contient « Autre / personnalisé » pour saisir une valeur libre.

4. Les mesures sont personnalisables :
   - bouton « Ajouter une mesure personnalisée » ;
   - nom libre de la mesure ;
   - valeur en cm ;
   - suppression d'une mesure personnalisée ;
   - conservation dans le JSON de mesures existant, sans migration de base nécessaire.
